# 检查项清单

## 当前覆盖范围

检查分成每次都跑的快检查，和可以缓存的慢检查。实际条数取决于代表页、sitemap 地址、图片、链接和结构化数据。

## 页面级检查

- HTTP 状态码符合预期。
- `<title>` 存在且达到最小长度。
- `meta[name="description"]` 存在且达到最小长度。
- H1 存在。
- canonical 存在。
- canonical 自指向最终公开 URL。
- hreflang 数量达到阈值。
- 存在 `x-default` hreflang。
- Open Graph 完整：`og:title`、`og:description`、`og:image`、`og:url`。
- Twitter Card 等于配置值，默认建议 `summary_large_image`。
- JSON-LD 存在。
- JSON-LD 必须能 parse。
- JSON-LD 包含配置指定的 schema 类型与必填字段。
- 图片都有非空 `alt`。
- viewport 存在。
- html lang 存在。
- 站内内链数量达到阈值。
- 内链不匹配异常格式正则。
- 内链不包含 legacy URL。
- 需要面包屑的页面存在可见面包屑。
- 详情页可配置返回列表页链接。

## sitemap 与可索引性

- sitemap index 可访问。
- 子 sitemap 可访问。
- sitemap URL 无重复。
- sitemap URL 不匹配禁止正则。
- sitemap URL 返回 200，除非配置允许 redirect。
- sitemap URL 深度审计：canonical 自指向、无 noindex、head 完整、JSON-LD 有效。
- sitemap 深度审计支持缓存，失败结果默认不缓存。
- 抽样页面内链不返回 404。
- 404 页面返回 404。
- 404 页面包含 `noindex`。
- noindex 页面 robots meta 包含配置值。
- legacy URL 返回 3xx 跳转。

## 静态 SEO 资产

- `robots.txt` 可访问。
- `robots.txt` 包含 `Sitemap:`。
- `robots.txt` 包含配置要求的抓取边界，例如 `Disallow: /api/`。
- `llms.txt` 可访问。
- `llms.txt` 包含配置要求的章节，例如 `Preferred Entry Points`。
- IndexNow key 文件可访问。
- IndexNow key 文件内容与配置一致。
- 配置的 favicon、apple-touch-icon、默认分享图等静态资源可访问。
- OG image / Twitter image / JSON-LD image 可配置检查 200 与 image content-type。

## 链接技术属性

- 页面内 href 不为空。
- 不允许 `javascript:` 链接。
- href 必须能解析为合法 URL。
- 内链不返回 404。
- `target="_blank"` 外链必须带 `rel="noopener"`。
- 命中 sponsored pattern 的外链必须带 `rel="sponsored"`。
- UGC selector 内的外链必须带 `rel="ugc"` 或 `nofollow`。
- 外链状态码可按 `off` / `sample` / `all` 配置检查。

## 缓存与分层执行

- 快检查每次都跑：robots、llms、sitemap、代表页、404、legacy redirect、host redirect。
- 慢检查默认读写 `.seo-gate-cache/`：sitemap HTML 深度审计、资源可访问性、链接扫描。
- `seo:audit` 使用缓存。
- `seo:audit:fresh` 不读旧缓存，但写入新缓存。
- `seo:cache:clear` 清空缓存。

## 线上一致性

- 浏览器 UA 页面返回 200。
- Googlebot 与浏览器拿到的 title 一致。
- Bingbot 与浏览器拿到的 title 一致。
- Googlebot/Bingbot 与浏览器拿到的 H1 一致。
- hreflang 示例页的目标链接都返回 200。

## IndexNow

- key location 可访问且内容匹配。
- 待提交 URL 非空。
- URL 去重。
- URL host 与站点 host 一致。
- URL 数量超过 `maxUrls` 时截断。
- `--dry-run` 输出完整 payload，不提交。
- 正式提交接受 HTTP 200 或 202。
